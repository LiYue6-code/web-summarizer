三步开始使用

1

加载扩展

打开 chrome://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」选择项目目录。

2

打开商品页

进入淘宝 / 京东 / 拼多多任意商品详情页，右下角出现「获取图片」按钮。

3

勾选并下载

点击按钮提取，在图库页勾选图片，点「下载选中」即可批量保存为 PNG。

安装指南

  1. 下载并解压本项目，得到 extension/ 目录。
  2. Chrome 地址栏输入 chrome://extensions 并回车。
  3. 右上角打开「开发者模式」开关。
  4. 点击「加载已解压的扩展程序」，选择 extension/ 目录。
  5. 固定工具栏图标，即可开始使用。

Q：下载到哪里？
